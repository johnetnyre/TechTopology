Digital access

Accessibility statement

Tech Topology aims to provide a website that is usable by the widest possible audience, including people using assistive technologies.

Design standard

This site is designed toward WCAG 2.1 Level AA. It uses semantic landmarks and headings, keyboard-accessible navigation, visible focus indicators, responsive reflow, accessible color contrast, reduced-motion support, and sufficiently large interactive controls.

Automated checks

The repository includes an automated accessibility test in GitHub Actions. Automated tools cannot verify every accessibility requirement, so content changes should also receive keyboard and screen-reader review.

Report a problem

If you encounter an accessibility barrier, email {{ conference.contact_email }} and describe the page and issue.
